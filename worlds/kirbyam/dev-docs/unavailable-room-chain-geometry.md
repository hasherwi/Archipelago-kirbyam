# Bomb-chain and approach supplement: native 819, 621 and 218

Checked **2026-11-08** using the verified USA ROM and [katam 7d969fb](https://github.com/jiangzhengwenjz/katam/tree/7d969fbce14fdc838d2c1ea01389717fb96c3189), committed 2026-09-17. This is independent source/static evidence, not recovered WiKirby prose. No new web requests, emulator sessions or gameplay changes were performed.

## Findings

**Olive Ocean Room 21, native 819:** The Bomb Block at **(27,12)** is directly exposed from below through ordinary water. A conservative clear-cell path runs from the actual native arrival center tile **(2,4)** to **(27,13)** without crossing metal or another solid tile. Conditional on successful activation, the exact chain changes **12 cells**, all to ordinary water **0x48**. This opens clear-cell connectivity to the existing exit at **(42,18) → native 821**; that exit remains **0xFD**, so the chain opens the intervening passage rather than creates the door. No chest object exists. This is a **directional underwater target candidate**, not an established wall-piercing requirement. The actual upward attack, player clearance and route still need acceptance testing.

**Radish Ruins Room 2, native 621:** Two separate chain groups form a sequence. The native arrival center is **(72,2)**. A clear-cell path reaches above the destroyable rock blocks at **(39,8)/(40,8)**. Assuming their independently recorded **F7→00** changes, the shaft reaches immediately above the lower Bomb Blocks **(39,16)/(40,16)**. Activating either lower bomb clears the same **six-cell** group to **00**. This opens clear-cell connectivity to **(20,12)**, immediately right of recessed bomb **(19,12)**. That upper bomb changes **50 cells**: the **48-cell rectangle x10–25,y8–10 becomes left-current water 0x65**, while (19,11) and the bomb cell itself become solid **0x0D**. The exit **(2,17) → native 605** remains **0xFF** and no chest exists. This supports a **sequential crumble/bomb route with an exposed right-hand target face**. Crumble contact, the narrow corridor, actual attacks and subsequent current traversal remain untested. The separate spike pit below the other rock-block row is not used by the recorded candidate path.

**Peppermint Palace Room 23, native 218:** Bomb **(2,4)** is exposed from the right. Its **13-cell** chain changes the exit tile **(5,4) → native 200** from **F3 to FF**, creating the transition property. Seven ceiling cells become hazard code **0x1D**; four other F3 cells and the bomb become **00**. No chest exists and the lower Hammer Peg is untouched. A qualified geometric route descends the right shaft, crosses near y31, then rises through the left one-way-platform shaft to the bomb's right face **(3,4)**. This probe explicitly admits only upward crossings of **0x0F** platforms; it is not a physics proof. The ordinary approach is therefore a concrete candidate, and a strict graph that excludes platforms cannot establish a wall-piercing requirement.

## Important collision distinctions

- **0x48 = attributes 0x00000003:** ordinary passable water, **not a slope**. The earlier “water-slope” description was wrong; the original scalar value was already correct.
- **0xF3 = attributes 0x00000041:** passable, chain-enabled terrain, **not a solid wall**. In native 218 the chain adds a door trigger to an already passable cell.
- **0x65 = attributes 0x04200803:** passable water with the leftward movement-override direction and strength index 2. The native movement-override tables select negative X values. Opening this region does not mean a current-free passage.
- These rooms have **no static small-switch or chest objects**. Their Bomb Blocks, the lower peg in 218, consumables, and existing exit doors must remain separate objectives.

## Source-backed method

The [attack collision branch](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/asm/code_08032E98.s#L7280-L7326) applies the seed mutation before starting the chain task. [Chain propagation](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/code_0800E0E4.c#L76-L165) processes left, above, right and below neighbors with collision attribute bit **0x40**, mutating each immediately before queueing it. Only F1/F2/F3 carry this bit in the pinned table. The decoder follows that order, uses the first matching current-tile mutation record, and verifies every replacement removes the chain bit. Maximum predicted wave size is six, below the native 32-coordinate frontier capacity. Wave sizes are algorithmic counts, not measured timing.

[Record lookup](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/code_080023A4.c#L1346-L1367) and [mutation application](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/code_080023A4.c#L586-L668) determine the exact replacement codes. [Door creation/activation](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/mirror_door.c#L44-L64) tests bit **0x4000**, absent in F3 and present in FF. [Native transition positioning](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/kirby.c#L12872-L12875) gives `x = spawnX×16−8`, `y = spawnY×16−7−1/256`, so arrival center tiles are the recorded spawn coordinates minus one, not the spawn labels themselves.

[Destroyable rock behavior](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/asm/object_spawner.s#L650-L934) checks Kirby position and state before its countdown and tile mutation; the sequence probe assumes those two mutations complete and does not simulate their triggering. [Current direction/strength handling](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/code_080023A4.c#L5606-L5680) and [override tables](https://github.com/jiangzhengwenjz/katam/blob/7d969fbce14fdc838d2c1ea01389717fb96c3189/src/code_080023A4.c#L433-L445) support the 0x65 interpretation.

## Evidence and limits

[Scalar chain and sequence evidence](unavailable-room-chain-geometry.json) contains the reviewed mutation records, arrivals, conditional cell paths, and validation results. Reproduction scripts remain with the local research artifacts.

A cell path is not controller input, a body-clearance proof or a gameplay witness. The strict probe uses only 00/48/F3/FD/FF cells; negative results deliberately omit slopes, platforms, currents and dynamic changes. The 218 extension models platforms as upward-only cell transitions. No result establishes a particular attack's eligibility, source acquisition, range, helper behavior or survival. No new ability capability is granted.
